# Claim-to-Code Mapping

This document maps each independent and dependent claim of TÜRKPATENT
application **2026/007632** to the specific code that implements it.
Use this as a reference when reading the patent alongside the implementation.

> The patent itself is in Turkish; this document uses the canonical English
> labels for the claims and refers to the relevant components by their figure
> labels (10, 11, 12, 13, 14, ...).

---

## Claim 1 — General hazard-based spiking neuron unit

**Patent text (paraphrased):** A spiking neuron unit having a leaky integrator,
a hazard circuit that converts membrane potential into firing probability, and
a Bernoulli sampler producing binary spikes.

**Code:**

| Component | File | Class / Function |
|-----------|------|------------------|
| Leaky integrator | `hlif_neurons/base.py` | `BaseNeuron.forward` (β·V + I update) |
| Bernoulli sampler | `hlif_neurons/base.py` | `spike_stochastic`, `StraightThroughBernoulli` |
| Surrogate gradient | `hlif_neurons/base.py` | `FastSigmoidSurrogate` (used by deterministic models) |

The simplest single-pathway hazard implementations are `BH-LIF` (barrier-only)
and `TH-LIF` (tunneling-only), both in `hlif_neurons/h_lif.py`.

## Claim 2 — Dual-pathway TH-LIF (canonical embodiment)

**Patent text (paraphrased):** The neuron unit of claim 1, where the hazard
circuit comprises two parallel sub-circuits: a threshold-crossing hazard
circuit (12) operating on supra-threshold membrane potential, and a
barrier-penetration hazard circuit (13) operating on sub-threshold membrane
potential via a tunneling analogy.

**Code:**

| Pathway | Math | Line in `h_lif.py` (THLIF class) |
|---------|------|----------------------------------|
| Barrier (13) | `lam_q = lam_0 * exp(-kappa * (phi_0 - eta * mem))` | `single_step` body |
| Combined output | `prob = 1 - exp(-lam_q)` | `single_step` body |

Note: pure TH-LIF in the current code uses only the barrier pathway. The
*dual-pathway* with both (12) and (13) is realized in `BH-LIF` (`BHLIF` class),
which has both `lam_cl` (sigmoid threshold-crossing) and `lam_q` (exponential
barrier-penetration). The patent claim is mathematically realized by their
sum `lam_cl + lam_q`.

## Claim 3 — Alternative realization forms of the hazard circuits

**Patent text (paraphrased):** The neuron unit of claim 2, where the
threshold-crossing hazard circuit (12) and barrier-penetration hazard circuit
(13) may alternatively be realized in:

- linearized form,
- sigmoid form, or
- λ₀ = 0 deterministic form.

**Code:**

| Form | File | Class |
|------|------|-------|
| Linearized | `hlif_neurons/h_lif_variants.py` | `THLIFLinear` |
| Sigmoid | `hlif_neurons/h_lif_variants.py` | `THLIFSigmoid` |
| λ₀ = 0 deterministic | `hlif_neurons/h_lif.py` | `DetLIF` |
| Sigmoid + Gaussian noise (a related stochastic variant) | `hlif_neurons/h_lif.py` | `StochLIF` |

The linearized form uses a piecewise-linear ramp `relu(1 + κ(η·V − φ₀))`
instead of the exponential. The sigmoid form uses
`λ_max · sigmoid(κ(η·V − φ₀))`. The deterministic form has zero base rate
(λ₀ = 0) and reduces to the classical Heaviside threshold.

## Claim 4 — Liquid extension (state-dependent hazard parameters)

**Patent text (paraphrased):** The neuron unit of claim 2, where the hazard
parameters κ and λ₀ are generated by a single-layer linear transformation of
the input signal (no external hypernetwork required), making the spike
mechanism itself input-dependent.

**Code:**

| Model | File | Class | Hazard params |
|-------|------|-------|---------------|
| L-TH-LIF | `hlif_neurons/liquid.py` | `LTHLIF` | `softplus(W_κ·x)`, `softplus(W_λ·x)` |
| L-BH-LIF | `hlif_neurons/liquid.py` | `LBHLIF` | both pathways' params input-dependent |

The liquid models also derive a state-dependent time constant
β_dyn = β·σ(W_τ·x) + (1−σ(W_τ·x))·0.5, which is part of the embodiment but
not separately claimed (it is an implementation detail of the input-dependent
formulation).

## Claim 5 — Physics-inspired hazard variants

**Patent text (paraphrased):** The neuron unit of claim 1, where the hazard
circuit implements one of the following physics-inspired mechanisms:

- double-barrier bistable potential,
- resonant tunneling band-pass response,
- thermal (Arrhenius) activation kinetics,
- magnetic spin precession,
- piezoelectric stress-induced threshold shift.

**Code:**

| Mechanism | File | Class | Distinguishing feature |
|-----------|------|-------|------------------------|
| Double-barrier | `hlif_neurons/h_lif.py` | `DBLIF` | Bistable, `excited` state variable |
| Resonant tunneling | `hlif_neurons/h_lif.py` | `RTLIF` | Gaussian peak at `v_peak` |
| Thermal | `hlif_neurons/h_lif.py` | `ThermalLIF` | `exp(-E_a / T)` Arrhenius factor |
| Spin precession | `hlif_neurons/h_lif_extensions.py` | `SpinLIF` | 2D spin vector `(s_x, s_z)` |
| Piezoelectric | `hlif_neurons/h_lif_extensions.py` | `PiezoLIF` | Stress-shifted dynamic threshold |

## Claim 6 — Architecture-inspired hazard modulation

**Patent text (paraphrased):** The neuron unit of claim 1, where the hazard
parameters are modulated by:

- cross-coupling between neurons in a layer,
- a mixture-of-experts gating network,
- a temporal attention mechanism, or
- a meta-network (hypernetwork) generating parameters dynamically.

**Code:**

| Mechanism | File | Class | Parameter generator |
|-----------|------|-------|---------------------|
| Cross-coupling | `hlif_neurons/h_lif.py` | `CHLIF` | `tanh(coupling) @ mem` modulates `phi_eff` |
| Mixture-of-experts | `hlif_neurons/h_lif.py` | `MoELIF` | Softmax over `n_experts=3` hazard functions |
| Attention | `hlif_neurons/h_lif.py` | `AttLIF` | Self-attention score lowers `phi_eff` |
| Hypernetwork | `hlif_neurons/h_lif.py` | `HyperNetLIF` | 2-layer MLP generates `(λ₀, κ, η, φ₀)` per step |

## Claim 7 (and following) — N-island heterogeneous neuromorphic system

**Patent text (paraphrased):** A neuromorphic processing system comprising
N independent neuromorphic islands, each containing one or more neuron units
of claim 1 with distinct hazard parametrizations, and a routing network with
modes selected from: static gating, semi-dynamic gating, fully-dynamic gating.

**Code:**

This claim covers a system-level architecture. The neuron units used inside
each island are the ones in `hlif_neurons/`. The routing network and the
training of the gating policy are out of scope for the reference
implementation in this repository; they will be the subject of a follow-up
paper. The companion patent **2026/004809** covers a specific two-island
realization (TH-LIF watchdog + conventional core) for battery management.

## Independent system-level metric — TNS (Temporal Necessity Score)

A normalized score `TNS ∈ [0, 1]` was introduced in the patent description to
quantify how much each neuron model relies on temporal information vs.
amplitude information for its decisions. SHD ablation results
(`Δ=17.4%` for TH-LIF when the temporal dimension is destroyed vs. `2.7%`
for standard LIF) confirm the discriminative power of the metric.

The TNS computation is not part of the neuron implementations themselves;
it is computed externally by running the SHD benchmark with and without
temporal shuffling. The code for that benchmark lives in the parent library's
`benchmarks/neurolimpics/` directory.

## How to verify the mapping

Each neuron class can be instantiated and tested independently:

```python
from hlif_neurons import HLIFRegistry

# Verify claim 5 (physics-inspired) models
for name in HLIFRegistry.list_by_claim("claim_5_physics"):
    n = HLIFRegistry.create(name, size=32)
    print(f"{name:15s} family={n.family}, params={n.learnable_param_count}")
    print(f"                 desc: {n.description}")
```

This produces a short audit trail of which class implements each claim
and what its learnable parameter count is.
